# 中国宏观经济仪表盘 · 兜底更新管线（周更）

> WorkBuddy / Claude 风格 Agent 的技能包：对既有「中国宏观经济仪表盘」（单文件离线 HTML）执行
> 周期性兜底更新——**补漏、刷新市场指标、滚动事件日历**，仅在有实质变化时才改文件。
>
> **自带管线模板与仪表盘模板**：首次使用自动初始化，无需手工搭建。

## 这个技能解决什么

宏观仪表盘建好后，数据会随发布日不断过期。本技能把"每周把看板刷到最新"固化成一条管线：

```
首次使用 → Step -1 自动初始化（复制内置管线+仪表盘模板）
全量取数（21 条查询，单一数据源）
  → 逐项比对（识别四类实质变化）
  → 条件更新（有变化才改单文件 HTML，红升绿降配色）
  → 交付归档（present_files + 写入执行记录）
```

**覆盖 21 项宏观指标**：中国 GDP / CPI / PPI / PMI / M2 / 社融 / 工业增加值 / 社零 / 固投 /
失业率 / 进出口 / 70 城房价 / LPR / 10 年国债 / 美元兑人民币中间价，以及美国非农 / CPI / ISM /
美联储利率路径等，外加滚动事件日历。

**核心纪律**：
- **单一数据源**：只用 NeoData 金融搜索，禁止混用其他来源、禁止用训练数据或推测补数；
- **无实质变化不改文件**：避免无意义改动污染历史；
- **发布日数据走资讯通道**：发布当天结构化 API 通常未入库，需改用资讯通道查询；
- **凭证静默处理**：任何场合不向用户展示、复述凭证内容；
- **事件日历不臆造日期**：未在资讯召回中出现的日期一律标"惯例"或留空。

**前置依赖（必装）**：
1. `neodata-financial-search` 技能——唯一数据源；
2. NeoData 金融数据服务访问权限——经 `connect_cloud_service` 获取凭证。

安装后重启/刷新会话，说"**更新宏观仪表盘**"即可触发：
- **首次使用**：自动初始化管线 + 仪表盘（从 `assets/` 模板复制），随后跑首轮全量更新；

## 依赖

**技能本体零第三方依赖**（纯方法论 + 模板 + 标准库脚本）。

**运行时依赖**（由宿主 Agent 提供，技能铁律约束）：

| 依赖 | 用途 | 说明 |
|---|---|---|
| `neodata-financial-search` 技能 | 唯一数据源，拉取 21 项宏观指标 + 事件日历 | 需配套安装该技能 |
| `connect_cloud_service` 工具 | 获取数据服务临时凭证 | 凭证失效时自动续期 |

**外部数据服务**：依赖 NeoData 金融数据接口（需该服务的可用凭证）。技能本体**不硬编码
任何 API Key**；凭证经 `connect_cloud_service` 动态获取并静默保存。

> ⚠️ 无 NeoData 服务权限的用户：技能无法取数，仪表盘无法建立或更新。

## 快速上手

| 步骤 | 动作 | 说明 |
|---|---|---|
| Step -1 | 首次初始化（自动） | 检测无管线 → 复制内置模板 → 告知用户 |
| Step 0 | 读执行记录 | 了解上轮结果与遗留事项（若有自动化） |
| Step 1 | 全量取数 | 跑 `dashboard_runner.py`，凭证失效自动续期 |
| Step 2 | 逐项比对 | 识别补漏/刷新市场指标/滚动日历/数据时点四类变化 |
| Step 3 | 条件更新 | 有实质变化才改 HTML，保持红升绿降配色 |
| Step 4 | 交付归档 | present_files + 写执行记录 |
